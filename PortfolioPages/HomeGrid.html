    HomeGrid

    Level Generation Tool — Unreal Engine

    HomeGrid is an Unreal Engine editor tool created for GradEx, The University of Staffordshire's annual graduate event. It allows designers to quickly create level blockouts, assign rooms, and save them for later level streaming. Inspired by a prototype from my Junior Collaborative Development module, this project extends that concept into a fully featured editor tool.
