    Multiplayer Mechanics Programming

    Unity Multiplayer Arcade Game

    For the Multiplayer Mechanics Programming module at The University of Staffordshire, I designed and programmed a wacky arcade machine with networked interactions. My goal was to replicate both world and UI changes across a network using remote procedure calls via the Unity Netcode for Game Objects plugin. The result is a vertical slice featuring 3 minigames and 4 configurations.
