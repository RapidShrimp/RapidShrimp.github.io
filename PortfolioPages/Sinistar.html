    Sinistar C++ Remake

    Low Level Gameplay Programming

    In the Low Level Gameplay Programming module at The University of Staffordshire, my task was to faithfully recreate a 1980s Williams Arcade Unit game from a small selection of games and improve upon the original.
    My selection was the game Sinistar. In creating this game I ended up making a small game engine using Object Oriented Programming to assist in the creation of this.
